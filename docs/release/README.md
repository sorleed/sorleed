# Release preparation

This directory contains the release process for Sorleed. Nothing here publishes
a package or creates a public release automatically.

| Document | Purpose |
|---|---|
| [`versioning.md`](versioning.md) | Version scheme and compatibility rules. |
| [`checklist.md`](checklist.md) | Pre-release and publication checklist. |
| [`publishing.md`](publishing.md) | npm publication steps and safeguards. |
| [`website-deployment.md`](website-deployment.md) | Static site deployment. |
| [`figma-delivery.md`](figma-delivery.md) | Figma library delivery and external actions. |
| [`notes-0.1.0-alpha.1.md`](notes-0.1.0-alpha.1.md) | Draft release notes. |

## Current status

- `@sorleed/react` 0.1.0-alpha.1 is private and unpublished.
- `@sorleed/cli` 0.1.0-alpha.0 is private and unpublished.
- No tags or GitHub releases exist.
- Publication requires the owner's explicit authorisation, npm credentials and
  a deliberate visibility decision.
