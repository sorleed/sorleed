# Figma

This directory is reserved for Figma source references and future exports.
Figma is a design source, not the code distribution.

- Button and Input have recorded Figma evidence in their contracts.
- PasswordInput and PhoneInput do **not** have verified Figma evidence. Their
  contracts record `canonical.figma: null` and null variant IDs. Do not invent a
  node ID.
- No Figma Community Library or export is included in this release. The
  component contracts and canonical CSS remain authoritative for
  implementation values.
