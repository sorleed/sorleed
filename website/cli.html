Sorleed CLI

Copy canonical source directly into your codebase. You own the code: inspect it, edit it, customize it. The CLI is safe by design and never overwrites existing code.

Commands

Terminal
# Show command list and usage
npx @sorleed/cli --help

# List all available components and dependencies
npx @sorleed/cli list

# Output components in machine-readable JSON format
npx @sorleed/cli list --json

# Add an individual component to your workspace
npx @sorleed/cli add balance-card

# Preview file operations without writing anything to disk
npx @sorleed/cli add balance-card --dry-run

# Specify custom target output directory
npx @sorleed/cli add balance-card --dir ./src/ui

Files Added to Your Workspace

When running add <component>, the CLI distributes clean TypeScript JSX and CSS files directly into your project structure:

Workspace Tree
components/sorleed/<component>/index.tsx
components/sorleed/types/index.ts      (shared types)
styles/sorleed/<component>.css
styles/sorleed/tokens.css              (shared design tokens)

Import design tokens first, followed by your component styles:

App.tsx
import "./styles/sorleed/tokens.css";
import "./styles/sorleed/balance-card.css";
import { BalanceCard } from "./components/sorleed/balance-card";

Conflict Protection

  • Zero Overwriting: Any existing component file halts execution immediately before writing to disk.
  • Shared File Integrity: Shared files (such as tokens.css and types/index.ts) are reused only when byte-identical to the canonical source.
  • Safe Rollbacks: On any copy error, any newly created files during that specific invocation are automatically rolled back.
  • Predictable Planning: Run with --dry-run anytime to review planned modifications beforehand.
