Toast

Production-tested Toast component for financial, banking, and wealth interfaces. Built with pure CSS tokens and zero runtime lock-in.

Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add toast

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { Toast } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/toast.css';

export function Example() {
  return (
    <Toast />
  );
}
