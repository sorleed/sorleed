Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add virtual-card-generator

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { VirtualCardGenerator } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/virtual-card-generator.css';

export function Example() {
  return (
    <VirtualCardGenerator />
  );
}
