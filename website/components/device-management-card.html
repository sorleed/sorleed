DeviceManagementCard

Active sessions and trusted devices security panel displaying device type, OS/browser, IP address, geolocation, and single or bulk session revocation.

Interactive Playground

Active Sessions

Manage devices currently signed in to your account.

Installation

Terminal
npx @sorleed/cli add device-management-card

React Usage

App.tsx
import { DeviceManagementCard } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/device-management-card.css';

export function Example() {
  return (
    <DeviceManagementCard
      sessions={[
        { id: '1', deviceName: 'MacBook Pro', deviceType: 'desktop', location: 'London, UK', lastActive: 'Active now', isCurrent: true },
        { id: '2', deviceName: 'iPhone 15 Pro', deviceType: 'mobile', location: 'New York, US', lastActive: '2 hours ago' }
      ]}
      onRevokeSession={(id) => console.log('Revoked', id)}
    />
  );
}
