Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add split-bill-calculator

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { SplitBillCalculator } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/split-bill-calculator.css';

export function Example() {
  return (
    <SplitBillCalculator />
  );
}
