GroupBillSplitFlow

Personal finance P2P bill splitting flow composing SplitBillCalculator, interactive friend selection, and a live payment request settlement tracker.

Interactive Playground

Dinner at Osteria — USD 180.00

USD 60.00 / person (3 ways)

Installation

Terminal
npx @sorleed/cli add group-bill-split-flow

React Usage

App.tsx
import { GroupBillSplitFlow } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/group-bill-split-flow.css';

export function Example() {
  return (
    <GroupBillSplitFlow
      defaultTotal={180}
      contacts={[
        { id: 'c1', name: 'Maya Lin', handle: '@mayalin' },
        { id: 'c2', name: 'Devon Brooks', handle: '@devonb' }
      ]}
      onSendRequests={(payload) => console.log(payload)}
    />
  );
}
