SessionTimeoutModal

PCI/banking inactivity session warning dialog with an animated SVG countdown ring, built on Radix Dialog with role="alertdialog" and pure CSS tokens.

Interactive Playground

00:60

Session Expiring Soon

For your security, you will be automatically signed out due to inactivity.

Countdown

Installation

Terminal
npx @sorleed/cli add session-timeout-modal

React Usage

App.tsx
import { SessionTimeoutModal } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/session-timeout-modal.css';

export function Example() {
  return (
    <SessionTimeoutModal
      open={true}
      countdownSeconds={60}
      onExtendSession={() => console.log('Extended')}
      onTimeout={() => console.log('Timed out')}
      onLogout={() => console.log('Logged out')}
    />
  );
}
