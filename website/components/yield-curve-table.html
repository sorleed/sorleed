Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add yield-curve-table

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { YieldCurveTable } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/yield-curve-table.css';

export function Example() {
  return (
    <YieldCurveTable />
  );
}
