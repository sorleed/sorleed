BeneficiaryPicker

Saved recipient and payee selector with Confirmation of Payee (CoP) verification status, payment rail badges, and live filtering.

Interactive Playground

Select Recipient

Interaction Type to filter or click any payee row

Installation

Terminal
npx @sorleed/cli add beneficiary-picker

React Usage

App.tsx
import { BeneficiaryPicker } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';

export function Example() {
  return (
    <BeneficiaryPicker
      beneficiaries={[
        { id: "1", name: "Acme Cloud Ltd", bankName: "Mercury Bank", accountMask: "•••• 4829", rail: "ACH", currency: "USD", verificationStatus: "verified" }
      ]}
      onSelect={(b) => console.log(b)}
    />
  );
}
