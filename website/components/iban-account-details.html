IbanAccountDetails

Local and international receiving account details sheet (IBAN, Routing, Sort Code, SWIFT/BIC) with sensitive field masking and one-click copy feedback.

Installation

Terminal
npx @sorleed/cli add iban-account-details

React Usage

App.tsx
import { IbanAccountDetails } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';

export function Example() {
  return (
    <IbanAccountDetails
      accountHolder="Sorleed Treasury Ltd"
      currency="EUR"
      railBadge="SEPA Instant"
      bankName="Commerzbank AG"
      bankAddress="Frankfurt am Main, DE"
      fields={[
        { label: "IBAN", value: "DE89 3704 0044 0532 0130 00", sensitive: true },
        { label: "SWIFT / BIC", value: "COBADEFFXXX" }
      ]}
    />
  );
}
