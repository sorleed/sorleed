Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add biometric-auth-prompt

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { BiometricAuthPrompt } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/biometric-auth-prompt.css';

export function Example() {
  return (
    <BiometricAuthPrompt />
  );
}
