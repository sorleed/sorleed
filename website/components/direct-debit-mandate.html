Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add direct-debit-mandate

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { DirectDebitMandate } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/direct-debit-mandate.css';

export function Example() {
  return (
    <DirectDebitMandate />
  );
}
