AuditTrailTimeline

Immutable financial and administrative event log displaying actor avatars, roles, severity badges, 2FA verification tags, and source IP addresses.

Preview

Audit Trail

Immutable ledger of administrative, treasury, and security actions

  1. Elena Vance(Treasury Admin)
    2026-11-19 14:22 UTC

    CRITICAL 2FA Verified IP 10.24.18.4

Installation

Terminal
npx @sorleed/cli add audit-trail-timeline

React Usage

App.tsx
import { AuditTrailTimeline } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/audit-trail-timeline.css';

export function Example() {
  return (
    <AuditTrailTimeline
      events={[
        {
          id: 'e1',
          actorName: 'Elena Vance',
          actorRole: 'Treasury Admin',
          action: 'Approved wire transfer',
          resource: 'TX-99412',
          timestamp: '2026-11-19 14:22 UTC',
          ipAddress: '10.24.18.4',
          mfaVerified: true,
          severity: 'critical'
        }
      ]}
    />
  );
}
