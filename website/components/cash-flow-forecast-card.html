CashFlowForecastCard

Treasury runway projection card comparing expected receivables vs scheduled payables across 30D, 60D, and 90D horizons with automatic runway calculation.

Preview

Cash Flow Forecast

11 mo runway
Projected Ending CashUSD 550,000

Installation

Terminal
npx @sorleed/cli add cash-flow-forecast-card

React Usage

App.tsx
import { CashFlowForecastCard } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/cash-flow-forecast-card.css';

export function Example() {
  return (
    <CashFlowForecastCard
      startingCash={500000}
      monthlyBurnRate={50000}
      periods={[
        { label: 'Month 1', inflows: 80000, outflows: 60000 },
        { label: 'Month 2', inflows: 90000, outflows: 60000 }
      ]}
    />
  );
}
