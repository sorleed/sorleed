Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add balance-card

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { BalanceCard } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/balance-card.css';

export function Example() {
  return (
    <BalanceCard />
  );
}
