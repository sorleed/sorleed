BeneficiaryManagementFlow

Beneficiary and vendor directory workflow composing Card, Tabs, Input, Select, BankSelector, OTP, Tooltip, Alert, Badge, and Button with add, OTP verification, and removal confirmation.

Installation

Terminal
npx @sorleed/cli add beneficiary-management-flow

React Usage

App.tsx
import { BeneficiaryManagementFlow } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';

export function Example() {
  return (
    <BeneficiaryManagementFlow
      accountType="business"
      onSaveBeneficiary={(b) => console.log('Saved', b.name)}
      onRemoveBeneficiary={(id) => console.log('Removed', id)}
    />
  );
}
