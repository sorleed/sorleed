VirtualCardReveal

PCI-aware virtual card surface with masked PAN/CVV, step-up authentication hook, 60-second auto-remask timer, and one-click clipboard copy.

Installation

Terminal
npx @sorleed/cli add virtual-card-reveal

React Usage

App.tsx
import { VirtualCardReveal } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/virtual-card-reveal.css';

export function Example() {
  return (
    <VirtualCardReveal
      cardNumber="4532 8920 1029 8841"
      cardHolder="ALEX MORGAN"
      expiry="08/29"
      cvv="412"
      brand="visa"
      theme="dark"
      autoMaskSeconds={60}
    />
  );
}
