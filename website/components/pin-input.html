PinInput

Production-tested PinInput component for financial, banking, and wealth interfaces. Built with pure CSS tokens and zero runtime lock-in.

Interactive Playground

State

Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add pin-input

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { PinInput } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/pin-input.css';

export function Example() {
  return (
    <PinInput />
  );
}
