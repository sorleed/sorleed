OrderEntryTicket

Brokerage order entry ticket with Buy/Sell tabs, Market/Limit/Stop order types, real-time buying power validation, and estimated total breakdown.

Interactive Playground

Microsoft Corp.

Installation

Terminal
npx @sorleed/cli add order-entry-ticket

React Usage

App.tsx
import { OrderEntryTicket } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/order-entry-ticket.css';

export function Example() {
  return (
    <OrderEntryTicket
      symbol="MSFT"
      companyName="Microsoft Corp."
      currentPrice={420}
      buyingPower={5000}
      availableShares={10}
      onSubmitOrder={(order) => console.log(order)}
    />
  );
}
