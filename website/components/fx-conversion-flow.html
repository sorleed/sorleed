FXConversionFlow

Multi-currency wallet conversion flow composing Card, Tabs, Select, Input, Tooltip, FeeBreakdown, TransferReceipt, Alert, Badge, and Button with currency swap and rate-lock expiry simulation.

Installation

Terminal
npx @sorleed/cli add fx-conversion-flow

React Usage

App.tsx
import { FXConversionFlow } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';

export function Example() {
  return (
    <FXConversionFlow
      accountType="business"
      fromCurrency="USD"
      toCurrency="EUR"
      availableBalance={25000}
      onConvert={(fx) => console.log(fx.reference)}
    />
  );
}
