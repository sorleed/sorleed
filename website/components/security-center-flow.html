SecurityCenterFlow

Unified account security hub composing DeviceManagementCard, VirtualCardReveal, SessionTimeoutModal, and an emergency account lockdown action.

Interactive Playground

Security Center

Protected
Emergency Account Lockdown Active — all other sessions terminated.

Suspect Unauthorized Access?

Immediately sign out all other devices and freeze exposed virtual card credentials.

Installation

Terminal
npx @sorleed/cli add security-center-flow

React Usage

App.tsx
import { SecurityCenterFlow } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/security-center-flow.css';

export function Example() {
  return (
    <SecurityCenterFlow
      devices={[]}
      cardNumber="4532 8920 1029 8841"
      cardHolder="ALEX MORGAN"
      cardExpiry="08/29"
      cardCvv="412"
      onEmergencyLockdown={() => console.log('Locked down')}
    />
  );
}
