PerformanceChartCard

Investment performance sparkline card with Radix Tabs timeframe switcher (1D, 1W, 1M, 1Y, ALL), return delta, and benchmark comparison.

Preview

AAPL +4.25%
Apple Inc.
USD 228.50 +USD 9.32 (1M)

Installation

Terminal
npx @sorleed/cli add performance-chart-card

React Usage

App.tsx
import { PerformanceChartCard } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/performance-chart-card.css';

export function Example() {
  return (
    <PerformanceChartCard
      symbol="AAPL"
      name="Apple Inc."
      currentPrice={228.5}
      returnPercent={4.25}
      returnAmount={9.32}
      benchmarkName="S&P 500"
      benchmarkReturn={2.1}
      dataPoints={[
        { label: 'Nov 1', value: 219 },
        { label: 'Nov 10', value: 224 },
        { label: 'Nov 19', value: 228.5 }
      ]}
    />
  );
}
