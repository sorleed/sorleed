Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add expense-receipt-uploader

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { ExpenseReceiptUploader } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/expense-receipt-uploader.css';

export function Example() {
  return (
    <ExpenseReceiptUploader />
  );
}
