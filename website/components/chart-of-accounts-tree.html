Installation

Add this component directly to your project using the Sorleed CLI:

Terminal
npx @sorleed/cli add chart-of-accounts-tree

Or install the full React library from npm:

Terminal
npm install @sorleed/react

React Usage

App.tsx
import { ChartOfAccountsTree } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/chart-of-accounts-tree.css';

export function Example() {
  return (
    <ChartOfAccountsTree />
  );
}
