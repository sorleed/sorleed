TradeExecutionFlow

End-to-end brokerage trade journey composing PerformanceChartCard, OrderEntryTicket, a review/NBBO confirmation step, and an execution receipt.

Interactive Playground

1. Configure Order→ 2. Review & Confirm→ 3. Execution Receipt

Installation

Terminal
npx @sorleed/cli add trade-execution-flow

React Usage

App.tsx
import { TradeExecutionFlow } from '@sorleed/react';
import '@sorleed/react/styles/tokens.css';
import '@sorleed/react/styles/trade-execution-flow.css';

export function Example() {
  return (
    <TradeExecutionFlow
      symbol="NVDA"
      companyName="NVIDIA Corp."
      currentPrice={140}
      buyingPower={5000}
      returnPercent={6.4}
      returnAmount={8.4}
      dataPoints={[{ label: 'Nov 1', value: 132 }, { label: 'Nov 19', value: 140 }]}
    />
  );
}
