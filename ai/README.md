# AI Context Files

The AI Context Layer described in the roadmap (`agent.md`,
`design-principles.md`, `coding-guidelines.md` and `prompts.md`) is **deferred**
beyond v0.1. No AI context files are implemented here.

For current human or AI-assisted consumption, use:

- the [component catalogue](../components/CATALOG.md);
- the [contract-first usage guide](../components/USAGE-GUIDE.md);
- the [implementation guide](../components/IMPLEMENTATION.md);
- the machine-readable contracts in `components/*/contract.json`.

Do not treat this directory as an implemented AI capability.
